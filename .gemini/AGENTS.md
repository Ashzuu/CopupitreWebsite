# Consignes permanentes

Pour chaque nouvelle tâche sur le projet Copupitre, veuillez suivre les consignes suivantes :
1. Lire les spécifications détaillées dans le cahier des charges et les user stories associées. (../../Cdc/*)
2. Lire les bonnes pratiques de développement et les conventions de code du projet. (ANGULAR_PRACTICES.md, CONTEXT.md)
3. Relis les logs dans .gemini/LOGS.md s'il y en a, sinon passer à l'étape suivante.
4. Une fois ta tâche terminée, explique de façon synthétique les choix techniques que tu as faits, les difficultés rencontrées et comment tu les as résolues dans le fichier LOGS.md (dans .gemini/)
